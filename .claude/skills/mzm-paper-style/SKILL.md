# MZM 论文文风改写（去 AI 味）

目标：让稿件读起来像微波光子学领域工程师写的中文期刊论文，而不是
论证严密到防御性的"审稿答复体"。参考样本是
`isbcscript/docs/paper/Dither-Based Bias Control ... V1.docx`（Ji 等）。

## 一、参考文风的特征（要模仿的）

1. **直陈句，一句一事**。主语是物理对象或实验动作（"OC 将光信号分为主路与监测路"），
   不是论证本身（"本文的核心增量在于……"）。
2. **固定学术套语，不追求新颖表达**：
   - 提出并（通过实验）验证了……；
   - 实验结果表明，……；与理论分析一致；
   - 为解决这一问题，……；由式 (10) 可知，……；
   - ……验证了该方案的有效性。
3. **引言三段式**：背景与重要性 → 按类别梳理文献（每项工作 1–2 句，
   "首先……随后……近期……"时间递进）→ 缺口一两句 + 本文做了什么。
4. **实验描述仪器先行、参数内联**："激光器（TLS1000）波长 1550 nm、线宽 100 kHz、
   输出 13 dBm"——名词短语铺开，不绕弯。
5. **结果按图走**："图 5(a) 给出……；图 5(b) 为……；结果与理论一致。"
   平行段落允许重复句式，不刻意变换。
6. **限定条件写成正面陈述**：把适用范围放进"在……条件下"里，
   而不是用否定句反复声明"本文不声称……""不能证明……"。
7. **术语一次定义、从一而终**，不换同义词花样。

## 二、要消除的"AI 味"病灶（针对本稿）

| 病灶 | 例（改前） | 改法（改后） |
|---|---|---|
| 审稿元话语 | "该差异是受控模型内检验，不是对已有文献实验精度的横向宣称" | "该比较在同一仿真模型内进行，用于隔离非对角校正的贡献" |
| "口径"腔 | "两种评价口径给出……" | "两种真值评价方法给出……"（表格行头除外，见硬约束） |
| 否定式免责声明连发 | "不支持……主张""不据此声称……""不能证明……" | 合并为一句正面限定："该结果表明……仅适用于……条件" |
| 名词化堆叠 | "完成硬件闭环验证" | "在硬件上验证了……闭环" |
| "增量/贡献"自评腔 | "本文的核心增量不是 X 而是 Y" | 直接陈述 Y 是什么、为什么需要 |
| 分号长串 + 多层插入 | 一句含 3 个分号、2 层括号 | 拆成 2–3 个短句 |
| 内联 (i)(ii)(iii) 过密 | 一段连用两组罗马编号 | 确有并列逻辑才保留，否则改为连贯叙述 |
| 破折号式补充 | "——那里同时满足：……" | 另起一句说明 |

判断标准：删掉这句话后读者会不会误解结论的适用范围？会——保留其实质、
换朴素说法；不会——删。**所有经审稿轮次加入的范围限定，实质必须保留**，
只允许改表达方式。

## 三、硬约束（违反即返工）

1. **任何数字、单位、数学式、`\label`/`\ref`/`\cite`/`\eqref`、图表结构一律不动。**
   `scripts/check.py` 会在全文任意位置搜索若干数值，删句子时不得把数字带走。
2. **两张表整体冻结**：`tab:results`（数值验证汇总）与 `tab:exp`（实验测试矩阵）
   的所有单元格、行头、脚注一字不改——number contract 按字面串和行头关键词匹配。
3. **以下正文字面串必须逐字保留**（check.py 按 substring 匹配）：
   - `15 个相邻步进中~14 个方向一致`
   - `16 个点的绝对误差均小于~$\pi/4$`
4. 定理、引理、命题、证明环境内的数学陈述不改；其中的说明性中文可微调。
5. 图 caption 可润色文字，但其中数字、`\ref` 与图内符号说明不动。
6. 改完后自查：
   ```bash
   grep -c '15 个相邻步进中~14 个方向一致' paper_mzm_zh.tex   # 必须 ≥1
   grep -c '16 个点的绝对误差均小于~\$\\pi/4\$' paper_mzm_zh.tex
   make check MAIN=paper_mzm_zh.tex                            # 0 FAIL
   ```

## 四、改写流程

1. 通读所辖章节，先列出该节的元话语句、超长句、否定式免责句。
2. 逐句改写：优先拆句和换主语，其次删纯元话语，最后统一术语。
3. 每处改动用 Edit 做最小替换，不整段重写（避免误伤数字与命令）。
4. 自查第三节约束，报告改动条数与代表性前后对照。
